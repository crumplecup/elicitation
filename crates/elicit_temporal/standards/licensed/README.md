# Licensed Standards Staging

Store the local working copies for licensed ISO temporal standards here.

These files are the authoritative corpus for tightening temporal contract doc
comments from topic-level labels to exact clause or subclause references.

Current corpus:

- `iso-8601-1-2019.sample.pdf`
- `iso-8601-1-2019.sample.txt`
- `iso-8601-1-2019-amd1-2022.sample.pdf`
- `iso-8601-1-2019-amd1-2022.sample.txt`
- `iso-8601-2-2019.sample.pdf`
- `iso-8601-2-2019.sample.txt`

Acceptable forms include searchable PDF, OCR text, or faithful HTML or text
extracts, provided clause numbering remains intact.

The current ISO artifacts are iTeh sample-preview working copies. They are
useful because they preserve table-of-contents clause numbering and selected
normative text passages, but they are not full licensed editions. Use them to
pin exact clause or subclause identifiers where the preview text is actually
present, and keep public cross-checks in place where the preview truncates the
normative body.

Use the `.txt` files for search and clause harvesting. Keep the paired `.pdf`
files because page boundaries, amendment pagination, and visual clause layout
sometimes disambiguate nearby citations better than OCR text alone.

Do not treat public catalog pages, heading summaries, or profile pages as
substitutes for this corpus.
